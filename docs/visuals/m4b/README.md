# M4b before and after

Before: `main` at f8ba7db (M4a merge plus the M4b plan), run from a scratch worktree. After: `m4b/buildings-streets` production build. Both on the high preset, 1280x720, pixel ratio 1, free orbit camera via `?cam=x,y,z&look=x,z`, HUD and mirror strip hidden, same framing, taken in the same session at noon and evening. Game coordinates: x east, z south, metres from the district origin 41.3111, 69.2797.

The three M4a spots use the M4a framings unchanged. The M4a after shots are not reused as before shots here: some were retaken in M4a fix rounds and none has the mirror strip handling or the evening pair, so all before shots are new.
