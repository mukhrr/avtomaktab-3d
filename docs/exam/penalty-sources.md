# Penalty sources

Primary source: Cabinet of Ministers decree No. 172 of 12.04.2022, "Yo'l harakati qoidalarini tasdiqlash to'g'risida", which approves the current Road Traffic Rules (YHQ). Read on lex.uz on 2026-10-23: https://lex.uz/mact/-5953883 (the text shows amendments up to 2024-11-30, decree 806). Clause numbers are the YHQ's own "band" numbers; "1-ilova" is Annex 1 (road signs), cited by sign number.

## Unverified

`clause: null, unverified: true` for these. No YHQ clause was seen that states the rule directly. No secondary source was used.

- collisionCar, collisionPedestrian, collisionObstacle: an exam fail for causing a crash. Clause 77 (safe speed for conditions) is the closest general duty, but it does not describe a collision rule.
- harshBraking: no clause bans hard braking. Clause 73 only mentions the car ahead braking hard.
- stall: engine stall is a driving-test criterion, not a YHQ rule.
- rollBack: rolling back on a start is a test criterion. Clause 63 covers reversing, not rolling back.
